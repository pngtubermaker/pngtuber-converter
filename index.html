2 PNGTuber Plus

A .save avatar with each frame set to show only while you're quiet, talking, blinking, or talking mid-blink.

  1. Open PNGTuber Plus and press Esc. Its avatar folder opens.
  2. Move the downloaded .save file into that folder. PNGTuber Plus only opens avatars from there.
  3. Click the Load button and pick the file.
  4. To zoom, hold Ctrl and scroll.

The folder, if you'd rather find it yourself: %APPDATA%\Godot\app_userdata\PNGTuberPlus on Windows, ~/Library/Application Support/Godot/app_userdata/PNGTuberPlus on macOS.

2 PNGTuber-Remix

A .pngRemix model with the four frames set to speak and blink. Written in the layout versions 1.3.5 through 1.4.7 open.

  1. In PNGTuber-Remix, choose Files → Open and pick the file, or drag the file onto the window.
  2. Save it from PNGTuber-Remix once it's open, so it's stored in the app's own current format.

2 veadotube mini and other apps

A ZIP of the four frames as PNGs, named for what they are.

  1. In veadotube mini, pick a state and put one file in each image slot: idle.png in the neutral face, talking.png in the screaming face, blink.png in the closed-eye face and blink-talking.png in the closed-eye screaming face.

Questions

Are my images uploaded anywhere?

No. This page builds the avatar file in your browser and nothing is sent to a server.

Why does PNGTuber Plus need the file in its own folder?

Its Load window only browses the app's data folder. Pressing Esc in PNGTuber Plus opens that folder, so you can drop the file in.

Can I use this in OBS without any app?

Yes: the PNGTuber OBS Player turns the same four frames into a file you add to OBS as a Browser Source. It talks when you talk, with no PNGTuber app running.

What size should my frames be?

All four the same size with a transparent background. 1024 × 1024 works well; bigger frames are scaled down to 1024 pixels on the long side.

Is this made by the PNGTuber Plus, PNGTuber-Remix or veadotube teams?

No. It's an independent tool that writes files those apps open. PNGTuber Plus is by kaiakairos, PNGTuber-Remix by MudkipWorld, and veadotube by olmewe.

Can I use the free characters on stream?

Yes, including on monetized Twitch and YouTube channels, with no credit required. They come from the Free AI PNGTuber Pack and were generated by AI with PNGTuber Maker.
